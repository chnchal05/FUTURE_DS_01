# Online Retail Sales Analytics Dashboard
### Future Interns – Data Science & Analytics | Task 01

## Project Overview
This project focuses on analyzing online retail sales data to understand business performance, identify sales trends, and generate meaningful business insights using Microsoft Excel.

## Dataset
- Dataset: Online Retail Dataset
- Original records: 541,909 rows
- Original columns: 8
- Domain: E-commerce / Retail

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Charts
- Excel Formulas
- GitHub

## Data Analysis & Preparation
The project involves:
- Checking and cleaning missing values.
- Examining negative quantities and invalid prices.
- Creating a Revenue column using Quantity × UnitPrice.
- Extracting Month from InvoiceDate.
- Preparing data for analysis using PivotTables.

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Quantity Sold
- Total Orders
- Total Customers

## Dashboard Visualizations
1. Monthly Revenue Trend
2. Top 10 Products by Revenue
3. Country-wise Sales Performance
4. Product-wise Quantity Analysis

## Business Objectives
- Identify top-performing products.
- Understand monthly sales patterns.
- Analyze country-wise revenue contribution.
- Support business decisions through data visualization.

## Project Deliverables
- Excel Sales Analytics Dashboard
- Online Retail Dataset
- Dashboard Screenshot
